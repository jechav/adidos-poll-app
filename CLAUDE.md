## Agent skills

### Issue tracker

Local markdown — issues live as one file per ticket at `docs/issues/I-0XX-<slug>.md`, indexed in `docs/issues/INDEX.md`. See [docs/agents/issue-tracker.md](docs/agents/issue-tracker.md).

### Triage labels

Default vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`), recorded as a `**Triage**:` line in each issue file rather than a platform label. See [docs/agents/triage-labels.md](docs/agents/triage-labels.md).

### Domain docs

Single-context — `DOMAIN_MODEL.md` at the repo root fills the `CONTEXT.md` role until `/domain-modeling` creates one; no `docs/adr/` yet. See [docs/agents/domain.md](docs/agents/domain.md).
